# Weeks et al. 2023: RNase III

## Study

Measured the fitness and RNA-cleavage activity of codon variants in the *Escherichia coli* `rnc` gene.

## Files

| File | Source and use |
|---|---|
| `RNC_ECOLI_Weeks_2023.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `Supplementary Data S8.csv` | Original author codon-level table from the [journal supplementary archive](https://oup.silverchair-cdn.com/oup/backfile/Content_public/Journal/mbe/40/3/10.1093_molbev_msad047/1/msad047_supplementary_data.zip). Provides the codons and weighted-mean functional scores used by the converter. The WT coding sequence is reconstructed from the blank WT entries. |
