# Adkar et al. 2012: CcdB

## Study

Measured the effects of single-amino-acid substitutions on the folding and activity of the *Escherichia coli* CcdB toxin.

## Files

| File | Source and use |
|---|---|
| `CCDB_ECOLI_Adkar_2012.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `Adkar_2012_CcdB_original_results_mmc2.xlsx` | Original author supplement from the publisher's [`mmc2.xls`](https://ars.els-cdn.com/content/image/1-s2.0-S0969212612000068-mmc2.xls), converted to `.xlsx`. Provides the mutant codons and `RankScore` values used by the converter. |
| `NC_002483.1_ccdB_CDS.fasta` | WT CcdB coding sequence downloaded directly from [NCBI accession NC_002483.1](https://www.ncbi.nlm.nih.gov/nuccore/NC_002483.1), coordinates 46560–46865. Used to construct the reported codon variants. |
