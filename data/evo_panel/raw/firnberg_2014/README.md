# Firnberg et al. 2014: TEM-1 beta-lactamase

## Study

Measured the effects of nucleotide and codon substitutions on TEM-1 beta-lactamase fitness across ampicillin concentrations.

## Files

| File | Source and use |
|---|---|
| `BLAT_ECOLX_Firnberg_2014.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `supp_msu081_Data_S1-S4.xlsx` | Original author supplementary data from the [published article](https://pmc.ncbi.nlm.nih.gov/articles/PMC4032126/). Sheet `S1 Codon fitnesses` provides the WT codons, mutant codons, and fitness values used by the converter. The WT coding sequence is reconstructed from this table. |
