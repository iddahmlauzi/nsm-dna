# Melnikov et al. 2014: APH(3')II

## Study

Measured the effects of amino-acid substitutions in APH(3')II on resistance to different aminoglycoside antibiotics.

## Files

| File | Source and use |
|---|---|
| `KKA2_KLEPN_Melnikov_2014.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `supp_gku511_nar-01049-met-h-2014-File006.xlsx` | Original author Supplementary Data 1 from the [published article](https://pmc.ncbi.nlm.nih.gov/articles/PMC4132701/). Provides the synthetic WT coding sequence and the exact oligonucleotides used to construct 4,997 nucleotide variants. |
| `supp_gku511_nar-01049-met-h-2014-File007.zip` | Original author Supplementary Data 2 from the [published article](https://pmc.ncbi.nlm.nih.gov/articles/PMC4132701/). Provides the selection measurements; the converter averages the two valid `Kan18` replicates. |
