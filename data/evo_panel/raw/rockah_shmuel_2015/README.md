# Rockah-Shmuel et al. 2015: HaeIII methyltransferase

## Study

Measured the effects of mutations accumulated during prolonged genetic drift on HaeIII DNA methyltransferase activity.

## Files

| File | Source and use |
|---|---|
| `MTH3_HAEAE_RockahShmuel_2015.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `pcbi.1004421.s002.xlsx` | Original author [S2 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s002&type=supplementary). Provides the reference codon at each position; the converter reconstructs the WT coding sequence from positions 0–331. |
| `pcbi.1004421.s003.xlsx` | Original author [S3 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s003&type=supplementary). Provides the G17 fitness scores for missense, synonymous, and nonsense mutations. |
