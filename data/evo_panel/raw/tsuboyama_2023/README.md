# Tsuboyama et al. 2023: Multiprotein folding stability

## Study

Measured folding stability for natural and designed protein domains using cDNA-display proteolysis.

## Files

| File | Source and use |
|---|---|
| `Processed_K50_dG_datasets.zip` | Original processed author dataset from [Zenodo record 7844779](https://zenodo.org/records/7844779). Provides construct nucleotide sequences, protein sequences, and `ddG_ML` scores. |
| `*_Tsuboyama_2023_*.csv` | Nineteen ProteinGym v1.3 prokaryotic protein-level assays extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Used to select the benchmark protein variants. The converter retains every matching author nucleotide sequence, including different codon backgrounds encoding the same protein. |
