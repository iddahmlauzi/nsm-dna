# Kelsic et al. 2016: Translation initiation factor IF-1

## Study

Measured how codon substitutions and local messenger-RNA structure affect the fitness of the essential *Escherichia coli* `infA` gene.

## Files

| File | Source and use |
|---|---|
| `IF1_ECOLI_Kelsic_2016.csv` | ProteinGym v1.3 protein-level assay, extracted from [Zenodo record 15293562](https://zenodo.org/records/15293562). Retained for comparison with the ProteinGym benchmark. |
| `NIHMS836960-supplement-1.csv` | Original author [Data S1](https://pmc.ncbi.nlm.nih.gov/articles/instance/5234859/bin/NIHMS836960-supplement-1.csv). Provides all codons, WT indicators, and rich-medium fitness values used by the converter. The WT coding sequence is reconstructed from rows marked `is_wt = 1`. |
