# Rockah-Shmuel et al. 2015: HaeIII methyltransferase

## Study

Measured the effects of mutations accumulated during prolonged genetic drift on HaeIII DNA methyltransferase activity.

## Files

| File | Source and use |
|---|---|
| `pcbi.1004421.s001.docx` | Original author [S1 document](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s001&type=supplementary). Describes read processing: 2,961 single-nucleotide mutations were observed and 2,907 remained after positional-bias and background-frequency filtering. |
| `pcbi.1004421.s002.xlsx` | Original author [S2 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s002&type=supplementary). Provides the reference codon at each position; the converter reconstructs the WT coding sequence from positions 0–331. |
| `pcbi.1004421.s003.xlsx` | Original author [S3 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s003&type=supplementary). Provides amino-acid-level `Wrel G17` scores and a table giving each codon's nucleotide distance from WT. The converter pairs each score with every one-nucleotide codon producing that amino-acid consequence. S3 does not identify which 54 of the 2,961 nucleotide mutations failed the authors' filters, so this reconstruction is not the exact 2,907-variant filtered panel. |
