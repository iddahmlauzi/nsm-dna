# Rockah-Shmuel et al. 2015: HaeIII methyltransferase

## Study

Measured the effects of mutations accumulated during prolonged genetic drift on HaeIII DNA methyltransferase activity.

## Files

| File | Source and use |
|---|---|
| `pcbi.1004421.s001.docx` | Original author [S1 document](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s001&type=supplementary). Describes read processing and defines the analyzed dataset as the 2,961 possible single-nucleotide codon substitutions. Double- and triple-nucleotide observations were retained only as raw data for possible future analysis. |
| `pcbi.1004421.s002.xlsx` | Original author [S2 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s002&type=supplementary). Provides the reference codon at each position; the converter reconstructs the WT coding sequence from positions 0–331. |
| `pcbi.1004421.s003.xlsx` | Original author [S3 workbook](https://journals.plos.org/ploscompbiol/article/file?id=10.1371%2Fjournal.pcbi.1004421.s003&type=supplementary). Provides the G17 fitness scores and identifies the exact single-nucleotide codons in the authors' analyzed dataset. The reported score combines codons that produce the same amino-acid mutation, so each corresponding nucleotide variant retains that shared score. |
