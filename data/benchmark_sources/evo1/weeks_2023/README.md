# Weeks et al. 2023: RNase III

## Study

Measured the fitness and RNA-cleavage activity of codon variants in the *Escherichia coli* `rnc` gene.

## Files

| File | Source and use |
|---|---|
| `Supplementary Data S1.xlsx` | Original author codon-level table from the [journal supplementary archive](https://oup.silverchair-cdn.com/oup/backfile/Content_public/Journal/mbe/40/3/10.1093_molbev_msad047/1/msad047_supplementary_data.zip). Provides the weighted-mean growth fitness used by Evo 1. |
| `Supplementary Data S8.csv` | Original author functional-score table from the same archive. Its blank WT entries recover the experimental coding sequence. The terminal `TGA` stop codon is restored to match the Evo 1 sequence. |
