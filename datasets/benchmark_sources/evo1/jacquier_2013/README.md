# Jacquier et al. 2013: TEM-1 beta-lactamase

## Study

Measured the amoxicillin resistance of single-amino-acid variants of TEM-1 beta-lactamase.

## Files

| File | Source and use |
|---|---|
| `1215206110_sd01.xlsx` | Original author supplementary data from the [published article](https://pmc.ncbi.nlm.nih.gov/articles/PMC3740883/). Sheet `TEM-1 DB` provides the nucleotide mutations and MIC scores used by the converter. |
| `J01749.1_TEM-1_CDS.fasta` | WT TEM-1 coding sequence downloaded directly from [NCBI accession J01749.1](https://www.ncbi.nlm.nih.gov/nuccore/J01749.1), complementary-strand coordinates 4153–3293. Used to construct each reported nucleotide variant. |
