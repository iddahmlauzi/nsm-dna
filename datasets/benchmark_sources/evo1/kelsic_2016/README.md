# Kelsic et al. 2016: Translation initiation factor IF-1

## Study

Measured how codon substitutions and local messenger-RNA structure affect the fitness of the essential *Escherichia coli* `infA` gene.

## Files

| File | Source and use |
|---|---|
| `NIHMS836960-supplement-1.csv` | Original author [Data S1](https://pmc.ncbi.nlm.nih.gov/articles/PMC5234859/). Provides the single-codon variants and the WT codons used to reconstruct the coding sequence. The first data row is omitted to match the Evo 1 artifact. |
| `NIHMS836960-supplement-2.csv` | Original author Data S2 from the same article. Provides the codon-pair variants and their rich-medium fitness values. The first data row is omitted, and repeated nucleotide sequences retain the first score, matching the Evo 1 artifact. |
