## NSM-DNA Questions

### Attention and conditioning

- Prefix + all earlier scales.
- Prefix + previous upsampled scale only (Markovian).
- Prefix represented at each scale; use only the matching resolution.
- Prefix represented at each scale; attend to all resolutions.

### Exposure bias

- Current baseline: nearest-neighbor noisy context + geometry loss.
- Soft conditioning with scheduled sampling.
- Two-pass student forcing (SAR): condition the second pass on first-pass
  predictions and match its outputs to the first-pass predictions. The released
  implementation uses hard teacher targets with cross-entropy, not KL. It
  reports FID 3.05 to 2.89; direct ground-truth-targeted student forcing was
  worse. [Zhou et al., 2025](https://arxiv.org/abs/2512.06421)
