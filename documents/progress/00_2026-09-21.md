# Week of September 21, 2026

## Hypothesis / question

Can biological structure in DNA provide a useful inductive bias for learned
tokenization? In particular, can a triplet bottleneck produce amino-acid-like
organization without codon or amino-acid supervision?

## Experiment

Triplet-compressed multiscale VQ-VAE:

Inductive bias: normalize the learned contribution of the first two bases as a
shared core, normalize the third base separately, then add it at 0.25 strength.
This encourages triplets with the same first two bases to remain close while
allowing the third base to refine or split the group.

Without this bias, reconstruction plateaued while code assignments remained
unstable, repeatedly switching among groupings based on different pairs of
triplet positions. With the bias, code assignments stabilized as reconstruction
converged.

```yaml
context_length: 384
latent_length: 128
quantization_dim: 16
third_base_scale: 0.25
scale_lengths: [1, 2, 4, 8, 16, 32, 64, 128]
codebook_sizes: [32, 32, 64, 64, 128, 128, 128, 32]
decay: 0.99
partial_reconstruction_weight: 0.25
reinitialize_codebook_step: 1000
num_epochs: 10
```
